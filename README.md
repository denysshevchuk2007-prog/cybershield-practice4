# CyberShield

Навчальний односторінковий сайт про цифрову безпеку з локальним HTTP API та SQLite. Інтерфейс українською, без зовнішніх JavaScript-бібліотек.

## Технології

- HTML, CSS і vanilla JavaScript
- Python 3.10+ зі стандартною бібліотекою
- SQLite для постійного зберігання повідомлень
- `unittest` та GitHub Actions для автоматичних перевірок

## Запуск локально (Windows PowerShell)

```powershell
$env:CYBERSHIELD_ADMIN_USER = "admin"
$env:CYBERSHIELD_ADMIN_PASSWORD = "встановіть-власний-пароль"
py backend.py
```

Відкрийте <http://127.0.0.1:8000>. Панель повідомлень доступна за адресою <http://127.0.0.1:8000/messages>. Пароль адміністратора задається тільки через змінну середовища; не додавайте його до Git чи ZIP.

Для macOS/Linux задайте змінні `CYBERSHIELD_ADMIN_USER` і `CYBERSHIELD_ADMIN_PASSWORD`, потім виконайте `python3 backend.py`.

## База даних

`schema.sql` описує таблицю `messages` та індекс за датою. Під час першого запуску сервер створює `data/messages.sqlite3`; дані залишаються після перезапуску. `data/`, журнали, секрети й середовище Python виключені через `.gitignore`. SQLite не використовує окремі облікові дані.

## Функції

- адаптивна сторінка, мобільне меню, світла/темна тема з `localStorage`;
- динамічні картки з додаванням і видаленням без перезавантаження;
- клієнтська та серверна перевірка форми;
- Fetch API надсилає форму на `POST /api/messages`;
- параметризовані SQL-запити;
- `GET /api/messages` і `DELETE /api/messages/{id}` доступні лише адміністратору;
- помилки сервера записуються в `data/server.log` з ротацією журналу.

## Автоматичні тести

Задайте тестові змінні середовища й виконайте:

```powershell
$env:CYBERSHIELD_ADMIN_USER = "ci-admin"
$env:CYBERSHIELD_ADMIN_PASSWORD = "ci-only-test-password"
py -m unittest discover -s tests -v
```

GitHub Actions автоматично запускає ці тести для кожного push і pull request. Тести перевіряють збереження та відновлення даних після перезапуску, відхилення некоректної форми, захист перегляду/видалення входом адміністратора та відповіді сторінок.

## Перевірка Lighthouse і адаптивності

У Chrome відкрийте DevTools → Lighthouse, виберіть Performance, Accessibility, Best Practices і SEO та запустіть аналіз для Desktop і Mobile. Запишіть фактичні бали та додайте знімок звіту до матеріалів здачі. Окремо перевірте ширини 375, 768 і 1440 px. У проєкті немає растрових зображень: ілюстрації створені CSS-ом; зовнішній вебшрифт прибраний, щоб сторінка не залежала від мережевого запиту до сервісу шрифтів.

## Публікація

Сервер прив’язаний лише до `127.0.0.1`. Не виставляйте навчальний сервер напряму в інтернет. Для публічного HTTPS-хостингу потрібен налаштований хост із підтримкою Python та постійного диска для SQLite або зовнішньої бази даних.
